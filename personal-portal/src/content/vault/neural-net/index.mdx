# 浏览器里的神经网络

这个 demo 里没有任何机器学习库,也没有预录的动画。左边那块画布上,一个只有两层的神经网络正在你眼前用真正的反向传播学习——每一帧都在做前向计算、算梯度、更新权重,决策边界因此一点点弯出形状。选它,是想把「神经网络在训练」这句常被神化的话拆开,让它变成几十行能读懂的算术。

## 它到底是什么

一个最小的多层感知机(MLP):

- **输入层**:2 个数,就是画布上一点的 `(x, y)` 坐标(已归一化到约 `[-1, 1]`)。
- **隐藏层**:10 个单元,激活函数用 `tanh`。这一层是关键——正是它让网络能表达非线性。
- **输出层**:1 个单元,`sigmoid` 压到 `0~1`,当作「这一点属于类别 A 的概率」。

权重一开始是小随机数。训练目标是二元交叉熵(BCE)损失,优化方法是最朴素的批量梯度下降。

## 反向传播在这里具体做了什么

每个 epoch,网络对全部样本走一遍这套流程:

1. **前向**:`z1 = W1·x + b1`,`a1 = tanh(z1)`;`z2 = W2·a1 + b2`,`out = sigmoid(z2)`。
2. **算损失**:`BCE = -[y·log(out) + (1-y)·log(1-out)]`。
3. **反向**:BCE 配 sigmoid 有个漂亮的巧合,输出层误差直接是 `out - y`,不用手动展开那一长串导数。再往回传时,`tanh` 的导数是 `1 - a²`,于是隐藏层每个单元的误差是 `(out - y)·W2·(1 - a1²)`。
4. **更新**:把所有样本累加的梯度平均一下,`W -= 学习率 · 梯度`。

这四步——前向、算损失、反传、更新——就是训练的全部。画布上边界的每一次弯曲,都是一次这样的权重更新的结果。demo 里显示的 `epoch` 和 `loss` 是从网络实时算出来的真实数字,不是写死的。

## 为什么非要有隐藏层

默认数据集是**同心环**:内圈一簇是类别 A,外圈一环是类别 B。这种分布**线性不可分**——你没法拿一条直线把里外分开。

如果去掉隐藏层,只留 `输入 → sigmoid`,那就退化成逻辑回归,能画的边界永远是一条直线,面对同心环必然失败。加上 `tanh` 隐藏层后,网络可以把 10 个单元各自的「半平面」弯折、叠加,拼出一条闭合的曲线边界,把内圈整个圈起来。训练几百个 epoch,你会看到中间浮起一座蓝色的「岛」——那就是网络学会的非线性边界。

## 你可以动手的地方

- **训练 / 暂停**:启动或停下训练循环(用 `requestAnimationFrame`,每帧跑几个 epoch)。
- **重置**:重新随机初始化权重、重播同心环数据集,从头再学一遍——每次初始权重不同,收敛出的边界细节也会不同。
- **切换笔刷 + 点击画布**:往画布上投放当前笔刷类别的样本。加几个「捣乱」的点,再继续训练,你能看到边界为了迁就新样本而变形——这就是「数据决定边界」最直观的样子。

## 这个玩具能做什么,不能做什么

**能**:在浏览器本地、不借助任何库,真实地演示一个神经网络如何通过梯度下降学出非线性决策边界;把「反向传播」从一个术语变成看得见的过程。

**不能**:它只有一个隐藏层、10 个单元,是不折不扣的**玩具**。没有批归一化、没有 dropout、没有动量或 Adam、没有训练/验证集划分,也谈不上泛化能力评估。样本点太少或摆得太刁钻时,它会过拟合甚至学不动。它解决不了任何真实问题,唯一的用途就是把「学习」这件事讲清楚。

## 诚实说明

画布里跑的是货真价实的网络:前向传播、反向传播、SGD 更新全部在 `src/demos/neural-net/index.tsx` 里手写,用的是纯 JavaScript 数学。它**不发起任何网络请求、不加载任何模型或机器学习库**。所有 `loss` / `epoch` 数字都来自这张网自己的计算。它是一个小得不能再小的 MLP,不多不少,就是它看起来的样子。
