# 生成海报

一个种子(seed)决定一整张海报:网格被分成若干格,每格按伪随机落下圆、方、斜线或半圆,配色取自站点主题。同一个 seed 永远画出同一张——所以它可复现、可分享、可下载。零依赖,纯 Canvas 2D。

## 实现要点

- 用 `mulberry32(seed)` 生成确定的伪随机序列:同 seed → 同序列 → 同构图。
- 先随机决定网格列数/行数,再逐格按概率选择形状与配色(强调色 / 前景色 / 底色)。
- 「重新生成」只是换一个随机 seed 并触发重绘;绘制本身完全静态,无动画。
- 「下载 PNG」通过 `canvas.toBlob` 导出当前画布,文件名带上 seed 便于复现。
- 监听容器尺寸变化重绘,保证任意比例下构图铺满;`createObjectURL` 用完即 `revoke`。
