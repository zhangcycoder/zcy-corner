# supET 工业互联网平台

这是一份基于历史简历整理的个人项目参与记录。它用于说明我在相关工业互联网产品中的前端工作，不是对整个平台建设过程的归属声明。

## 平台背景

supET 当前公开站点以“阿里云工业互联网平台官网”为题，公开能力包括工业设备连接、数据采集、设备运维、生产管控可视化、协同制造、智能仓储与产业大脑。这些内容来自平台公开信息，用于交代产品背景，不等同于我的个人贡献。

## 我的参与

根据自 2021 年 4 月起的历史简历记录，我参与过 supET 相关工业互联网产品的需求评审、排期、前端系统设计评审、功能开发、提测与发布文档，并参与 Node 镜像构建。

前端工程侧包括将既有 UI 体系迁移至 Link Design / Fusion、移除 DVA model 层并按组件组织状态与请求边界，以及参与 CMS 2.0 的权限、路由、数据结构、Layout、HOC 和跨页面能力建设。

## 代表模块

- **工业区行平台**：参与云网关激活与进度、设备点表上传校验、驱动分配、云端配置与下发、远程隧道 / VPN、门户配置、服务商入驻、账号续费与权限标签。
- **小蜜蜂本地控制台**：使用 React 与飞冰参与边缘网关初始化和服务管理，覆盖总览、Wi-Fi、4G、设置、日志、登录与 Token、基础信息和限流。
- **马良组态**：参与画布编辑、运行时数据源与属性配置、复制删除同步、图表与基础组件、自动保存、代码输入和 SVG 素材管理。
- **通义智物**：参与多模态会话、知识库创建测试与批量维护、角色账号权限、通用页面结构与图表监控。

## 工程方法

- 让组件持有自身状态与请求边界，减少对集中 model 层的依赖。
- 在 UI 体系迁移过程中同步梳理数据、权限和跨页面能力。
- 通过全局事件更新边缘控制台的实时网络状态，并参与性能与包体优化。
- 将需求评审、排期、系统设计评审、提测和发布文档纳入交付过程。
