# Canvas 粒子力场

这是原始个人门户的粒子背景实验。新版网站不再把持续动画放在首页，而是把它降级为一件可以独立运行、也能复盘的**早期藏品**——它更像"当时是怎么写的"的记录，而不是现在的代表作。

## 实现要点

- **Canvas 2D 逐帧绘制**,约 80 个粒子，由 `requestAnimationFrame` 驱动。
- **最朴素的欧拉积分**:每帧只做 `x += vx`,不加阻尼也不加重力——所以粒子不会衰减停下，呈现的是一片持续漂浮的力场，而非物理仿真。
- **指针排斥**:光标进入半径 150px 内，按"越近越强"的线性衰减把粒子推开 (力度系数 0.5)。
- **边界反弹**:粒子触边即把对应方向的速度取反。
- **诚实的边界**:交互只监听 `mousemove`,所以这是鼠标力场、**触屏无效**;这是早期实现的局限，没有粉饰。
- **稳妥收尾**:卸载时取消动画帧、移除监听;Canvas 不可用或系统开启"减少动态效果"时，直接降级成一张静态径向渐变背景，不硬跑动画。
