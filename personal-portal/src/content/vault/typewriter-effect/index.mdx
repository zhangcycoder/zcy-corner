# 循环打字机模块

这是原始门户里的循环打字标题效果，收进早期实验作为一件可复用模块。重点不在动画本身，而在**用一个明确的状态机**把打字、停顿、删除、切换四个阶段管起来——避免用几个互相纠缠的布尔量在定时器里拼流程，那正是这类效果最容易写乱的地方。

## 状态机

- 用 `useReducer` 把流程收敛成五个动作：追加字符、删除字符、进入停顿、结束停顿、切换下一段。每一拍只推进一个明确的状态，不在 `setTimeout` 回调里塞条件分支;当前状态用一个 ref 读取，避免闭包读到过期值。
- **四个阶段**:按固定间隔逐字追加 → 整段显示后停顿 → 以约两倍速度 (间隔减半) 逐字删除 → 切到下一段循环。
- 字符间隔上限锁在 100ms，防止传入过大的值让节奏拖沓;光标闪烁交给 CSS `@keyframes`,不占 JS 逐帧。
- **无障碍**:文本区标 `aria-live="polite"`,读屏能感知内容变化;系统开启「减少动态效果」时**不跑打字循环**,直接静态呈现首段文字;组件卸载时清理定时器。

对外只暴露三个参数：文字数组、字符间隔、停顿时间。
