# 流场墨迹

粒子沿一片看不见的「流场」漂移,把轨迹留成墨痕——像墨滴落在宣纸上顺着纹理蔓延。零依赖,纯 Canvas 2D。

## 实现要点

- 流场由多个不同频率的正弦/余弦叠加而成,给平面上每一点一个方向角。
- 上千粒子每帧读取所在位置的角度并前进一步,画出上一帧到当前帧的短线段。
- 每帧用极低透明度的纸色覆盖一次,旧墨迹缓慢淡出,形成流动而不糊死的层次。
- 指针或触摸进入影响半径时,叠加一个指向光标的角度偏置,局部流向被「拨动」。
- 颜色从主题 CSS 变量读取(墨=强调色,纸=画廊底色),自动契合站点配色。
- 开启系统「减少动态效果」时只渲染一帧静态快照;组件卸载时取消动画帧、断开 ResizeObserver、移除指针监听。
