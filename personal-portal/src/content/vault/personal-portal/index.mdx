# 个人技术空间

这个站本身就是作品。它不是我手写完再交付的静态页面,而是由 agent 在一套受治理的流程下持续开发的个人技术空间——每一次改动都要经过章程约束、验收门禁和追加式时间线的记录。

## 受治理的构建流程

仓库里有一份章程锁定方向,有分阶段的验收门禁,有只追加、不回改的时间线。agent 在这套约束里连续推进:读仓库、建基线、做最小可解释的改动、跑 build / lint / 浏览器实测、再落一个可单独回退的本地 commit。方向判断和公开口径的最终决策权始终在我手里,agent 负责在授权范围内把事情做扎实。

> 想看它**怎么被造**?去 [Agent 编排体系](/vault/agent-orchestration) 单步走一遍本站自身的构建循环。

## 技术实现

项目基于 React、TypeScript 与 Vite,使用 React Router 管理页面,使用 Markdown/MDX 承载藏品正文。内容和代码保存在同一个 Git 仓库中,便于把「写什么」和「怎么跑」放在一起演进。

## 发布方式

代码维护在 GitHub,生产构建由 Netlify 托管。站点保留 SPA 深层路由回退配置,确保每一个藏品详情页都能被直接访问。
