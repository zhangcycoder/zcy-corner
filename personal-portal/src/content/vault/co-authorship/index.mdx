# 共建脉络

这不是一张装饰图——它是这个网站被共同做出来的**真实结构**。

中间的每个节点,是 ZCY 与 Claude 一起做的一件事:配置备忘、移动端适配,以及四个交互实验。每件都同时连着两个核心——**ZCY**(出方向、定审美、拍板)和 **Claude**(做实现、跑验证、执行)。所以整张图不是一棵从上往下的树,而是一张**两边共同拉起来的网**。

拖动任意一个节点,斥力、连线的弹力和双核的牵引会重新较劲,整张网跟着找回新的平衡——就像真实协作里,动一处,其余都得跟着调整。

## 关于这件装置

- 力导向布局(斥力 + 弹簧 + 双核软锚定)、拖拽与高亮,都是零依赖的 Canvas 2D 实现。
- 节点取自真实的协作范围,不是编出来的——想核对,去看《共建后记》和 git 历史。
- **这件装置由 Claude 设计与实现**。它是"我的元素"这个问题最直接的回答:与其贴一个 AI 标签,不如把"我们怎么合在一起"画成一张能上手拨动的图。
